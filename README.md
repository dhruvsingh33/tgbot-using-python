# 🤖 ClickNPick Telegram Bot

A Telegram bot that converts normal E-com product links into affiliate links. Built using `python-telegram-bot` and deployed.

## Features
- Converts Normal links to affiliate links
- Tracks number of links per user
- SQLite database integration
- Inline buttons for better UX

##Tech Stack
- Python
- Telegram Bot API
- SQLite
- Flask (for uptime ping)
